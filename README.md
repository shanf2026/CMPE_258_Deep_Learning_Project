### 📝 Abstract
This project introduces **Arcade Stress Benchmark**, an open-source diagnostic evaluation framework designed to stress test and analyze three distinct architectural AI model classes across classic Atari environments (such as *Montezuma’s Revenge, Space Invaders, Ms. Pac-Man, and Asteroids*):

* **Deep Reinforcement Learning:** Agent57, Rainbow
* **World Models:** DreamerV3
* **Vision Large Language Models (VLLMs):** GPT-4, Claude

The framework evaluates model robustness using three primary performance lenses:
* **In-Game Performance:** The total score achieved by the agent within the environment.
* **Resource Efficiency:** The computational overhead, time, and physical hardware resources required to produce results.
* **Real-Time Feasibility:** A strict evaluation of whether the architecture can maintain real-time execution speeds at **60 frames per second (fps)**.
